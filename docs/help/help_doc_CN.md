# 帮助 - 如何使用 24 Solver

24 Solver，是一个解决[算24]问题的计算器，但它不局限于此。给它一点时间，它可以找到这些问题的全部解，也可以解决[算10]问题或[算-24]问题。

**如何使用**：
就像真正的计算器一样，使用数字键盘键入候选数。键入的候选数会在[输入]显示。当你认为你的键入正确，按下[确认]来储存此候选数，或者轻按[退格]来清除错误。如此炮制以填入全部的候选数（1至5个），按下[求 解]，完成。

按下[目标]，可以更改目标数，再次按下[目标]来存储，以解决[算X]问题。如果你偏爱某个[算X]问题，可以在右上角设置修改。

长按[清空]或[退格]，我们准备了惊喜。

键盘声可以在右上角设置关闭。

在设置中可以重新打开此帮助。
