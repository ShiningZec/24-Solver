# ヘルプ - 「24 Solver」の使い方


「24 Solver」は、「メーク24パズル」を解くための計算ツールですが、それだけに限定されません。少し時間をかければ、「メーク10」や「メーク-24」など、これらの問題のすべての解を見つけ出すことができます。

**使い方**：
電卓と同じように、テンキーを使って数字を入力します。入力した数字は「入力」欄に表示されます。入力内容に間違いがなければ、「確定」キーを押してその数字を確定・保存してください。間違えて入力してしまった場合は、「削除」キーを押して修正できます。

同様の手順ですべての数字（1〜5個）を入力し終えたら、「計算開始」を押して計算を実行します。

「目標」を押すと、目標とする数値を変更できます。もう一度「目標」を押して確定すれば、その数値を目指すパズル（「メークX」）を解くことができます。特定のパズル設定を好む場合は、画面右上の設定から変更可能です。

「クリア」や「削除」を長押しすると、ちょっとしたサプライズがあるかもしれません。

また、キー入力音は、設定からオフにすることができます。

誤って閉じてしまった場合は、設定からこのヘルプページを再度開くことができます。
